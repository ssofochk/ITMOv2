# Делим — UI спецификация

Делим — небольшое веб‑приложение для распределения совместных расходов между друзьями. Этот репозиторий содержит независимую спецификацию пользовательского интерфейса (UI) для первой версии продукта. Реализация логики расчётов и генерация кода будут выполняться отдельной командой после согласования двух спецификаций.

Содержимое:
- `docs/brief.md` — краткое продуктовое описание и ограничения первой версии.
- `docs/ui-spec-v1.md` — полноценная UI‑спецификация по принципам GitHub Spec Kit.
- `docs/ui-open-questions.md` — вопросы и допущения для согласования с командой бизнес‑логики.

Ограничения этапа:
- Не создаём и не генерируем код приложения.
- Не проектируем бизнес‑логику расчётов.
- Настраиваем Spec Kit локально в рамках каталога проекта без изменения корпоративной конфигурации OpenCode.
