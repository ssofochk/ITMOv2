# Делим — приложение для разделения расходов

Делим — веб‑приложение для распределения совместных расходов между друзьями.

Что реализовано:
- Добавление участников, валидация уникальности имён.
- Добавление расходов с выбором плательщика и участников.
- Равное распределение расходов; детерминированное распределение остатков копеек.
- История расходов, удаление записей.
- Расчёт балансов и рекомендации переводов.
- Сохранение и восстановление из localStorage.

Установка и запуск:
- Перейти в `practices/practice_05/delim/app`.
- Установить зависимости: `npm install`.
- Запустить dev‑сервер: `npm run dev`.
- Тесты: `npm test`.
- Сборка: `npm run build`.
- Проверка типов: `npm run typecheck`.
