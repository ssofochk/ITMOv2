# Делим — краткое описание

Делим — веб‑приложение для разделения совместных расходов между участниками одной компании (поездка, мероприятие, вечеринка). Пользователь добавляет участников, фиксирует расходы (название, сумма, плательщик), отмечает, между кем делится каждая трата, просматривает историю, удаляет ошибки, видит личные балансы и получает список рекомендуемых переводов «кто кому сколько должен». Данные сохраняются локально между перезагрузками.

Первая версия:
- Один общий счёт, одна валюта (рубли), без авторизации.
- Без внешнего бэкенда и банковских интеграций.
- Локальное хранение (localStorage).
- Предполагаемый стек: React, TypeScript, Vite, Vitest.

Нефункциональные требования (UI уровень):
- Современный аккуратный интерфейс, не «демо‑todo».
- Адаптивность: корректная работа на мобильных и десктопах.
- Доступность: фокусируемость, контраст, читаемые подсказки, поддержка клавиатуры.

Границы этапа:
- Формируем только независимую UI‑спецификацию.
- Бизнес‑логика будет спроектирована отдельно; интерфейсы взаимодействия описаны как ожидания UI.
