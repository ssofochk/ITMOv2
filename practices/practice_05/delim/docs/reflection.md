# Делим — рефлексия

Сложности:
- Независимые предположения команд: UI ожидал строки и ISO‑время, логика — UUID и epoch; решено унификацией в контракте.
- Денежные правила: распределение остатков копеек и детерминизм — принята логика с сортировкой по UUID.
- Интеграция Spec Kit: установлен `specify-cli 1.2.5`, но бинарь отсутствует в PATH и модуль не запускался — использованы локальные шаблоны `.specify` и артефакты созданы вручную.
- Тестовая среда Vitest: согласование setup и конфигурации с Vite 8.

Решения:
- Жёсткий контракт с типизированными ошибками.
- Полностью целочисленные денежные вычисления; UI не дублирует логику.
- Локальный SDD-процесс, прозрачная фиксация артефактов и хешей.
