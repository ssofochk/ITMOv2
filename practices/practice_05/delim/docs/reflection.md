# Делим — рефлексия

Что согласовали:
- Единый контракт UI ↔ Логика: входы `UpdateExpenseInput`, атомарность, детерминизм, сортировки, политика архивированных участников, коды ошибок и их маппинг на UI.
- Границы ответственности: UI отображает и валидирует на основе логических кодов; логика обеспечивает инварианты и ошибки.

Проблемы и решения:
- Привязка CLI/агентов: `/speckit.analyze` — slash-команда, запуск через OpenCode; для prereq использовали `.specify/scripts/...` и SPECIFY_INIT_DIR.
- Валидация OpenSpec: `validate --specs` пуст без main-specов; решили завершить планирование и зафиксировать change, sync/validate — на финале.
- Дублирующий путь в `feature.json`: исправили на относительный `specs/...` для корректного резолвинга.

Чему научились:
- Дисциплина SDD: окружение, nested-проекты, артефакты и истории важны для доказуемости.
- Две независимые команды повышают качество: согласование до генерации кода снижает риски и упрощает реализацию.
