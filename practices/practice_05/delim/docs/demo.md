# Делим — сценарий демонстрации

1. Открыть приложение «Делим» (локально `npm run dev`).
2. Добавить участников: «Аня», «Маша», «Дима».
3. Перейти во вкладку «Расходы».
4. Добавить расход: «Жильё», сумма 4500 ₽, плательщик «Аня», участники: все трое.
5. Добавить расход: «Продукты», сумма 1500 ₽, плательщик «Маша», участники: все трое.
6. Открыть вкладку «Балансы»: увидеть нетто +2500 ₽ у Ани, −500 ₽ у Маши, −2000 ₽ у Димы.
7. Открыть вкладку «Переводы»: «Маша → Аня: 500 ₽», «Дима → Аня: 2000 ₽».
8. Перезагрузить страницу — данные восстановлены из localStorage.
