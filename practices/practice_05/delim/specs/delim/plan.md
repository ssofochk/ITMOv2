# Делим — технический план (SDD)

Дата: 2026-10-30
Спецификация: `specs/delim/spec.md`

## Структура проекта

```
practices/practice_05/delim/
  docs/            # спецификации, отчёты
  specs/delim/     # артефакты Spec Kit (spec, plan, tasks, etc.)
  app/             # исходный код приложения
    src/
      contract/    # TS-типы и интерфейсы
      logic/       # чистая бизнес-логика
      storage/     # слой localStorage
      ui/          # React компоненты
      tests/       # Vitest
    index.html
  package.json
  vite.config.ts
  tsconfig.json
```

## Технологический контекст

- Язык: TypeScript.
- Фреймворк: React + Vite.
- Тесты: Vitest.
- Хранение: localStorage.

## Ключевые решения

- Контракт как единственный источник типов (`docs/contract.md`).
- Денежные расчёты полностью в `logic/`, UI не дублирует вычисления.
- Снапшот состояния хранится/восстанавливается через `storage/`.

## Порядок работ

1. Создать каркас Vite + TS, настроить Vitest.
2. Реализовать контрактные типы (генерация/копия из `docs/contract.md`).
3. Реализовать бизнес-логику: участники, расходы, балансы, переводы, сериализация.
4. Реализовать слой хранения: ключ `delim:v1`, обработка ошибок.
5. Реализовать UI: вкладки, формы, списки, таблицы, тосты.
6. Написать тесты по обязательным сценариям.
7. Сборка, проверка типов, запуск тестов, фиксация результатов.

## Ограничения

- Не использовать floating point для хранения денег; все суммы — копейки.
- Не добавлять внешний бэкенд.
