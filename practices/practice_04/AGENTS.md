# AGENTS.md

## Правила работы для practice_04

- Источник требований этой работы: `practices/practice_04/README.md`
- Изменения для домашней работы должны быть минимальными и относиться к practice_04
- При разработке кода для practice_04 использовать skill `test-driven-development`
- Сначала получать проверяемый failing case/test, затем реализацию, затем успешную проверку
- Документацию библиотек при необходимости искать через Context7, а не придумывать API
- Когда позже появится `practices/practice_04/scripts/check.sh`, использовать его как основной runner
- Нельзя ослаблять или изменять проверки только ради зелёного результата
- Нельзя сообщать об успешной проверке, если команда фактически не была выполнена
- Существующую конфигурацию моделей/provider'ов в `opencode.json` без необходимости не менять
