---
description: Generate or update the feature checklist based on specification and plan.
---

## Inputs

```text
$ARGUMENTS
```

Use arguments to focus on particular checklist categories (e.g., "requirements", "testing").

## Steps

1. Locate current feature directory from `.specify/feature.json` or by scanning `specs/`.
2. Read `spec.md` and `plan.md` if available.
3. Create or update `checklist.md` with sections:
   - Content Quality
   - Requirement Completeness
   - Feature Readiness
   - Testing & Validation
4. Fill checklist items with concrete, verifiable bullets derived from the spec/plan.
5. Avoid implementation details; keep criteria user-value focused and testable.
6. If the checklist exists, preserve manual edits while refreshing autogenerated sections.

## Output

Write to `SPECIFY_FEATURE_DIRECTORY/checklist.md` and summarize changes.
