description: Create or update the technical plan from the feature specification.
---

## Inputs

```text
$ARGUMENTS
```

Treat arguments as constraints or priorities to incorporate into planning.

## Steps

1. Load `spec.md` and constitution.
2. Derive objectives, scope boundaries, risks, and milestones.
3. Propose a minimal architecture with clear interfaces (avoid implementation specifics).
4. Write to `SPECIFY_FEATURE_DIRECTORY/plan.md` preserving section order.
5. Summarize plan and next steps.
